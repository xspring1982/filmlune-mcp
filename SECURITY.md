# Security policy

`filmlune-mcp` is a read-only local stdio server. It never accepts credentials,
writes catalog data, or calls an image or video provider.

Please report a suspected vulnerability through the repository's private
security-reporting channel when one is available. Do not include access tokens,
private media, personal data, or other secrets in a public issue.

The public catalog is generated by the FilmLune website workflow and verified
before server startup. A validation failure blocks startup rather than falling
back to stale or partially trusted content.
